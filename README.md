# 🔐 Web Server Hacking Lab (CEH Module 13)

## 📌 Objective

This project demonstrates practical web server reconnaissance, scanning, and enumeration using ethical hacking techniques.

## 🎯 Target

https://testphp.vulnweb.com

---

## 🧠 Methodology

### 1. Reconnaissance

* WHOIS lookup
* DNS enumeration (dig, nslookup)

### 2. Scanning

* Tool used: Skipfish
* Identified site structure and potential vulnerabilities

### 3. Enumeration

* Tool used: Gobuster
* Discovered hidden directories such as `/admin`, `/login`

---

## 🛠 Tools Used

* WHOIS
* DIG / NSLOOKUP
* Skipfish
* Gobuster
